# Bahamut/pages/theme

## 概述
theme 模組提供應用程式主題管理功能，支援自訂色彩和主題切換。

## 主要元件

### Theme
主題資料模型，定義主題的色彩配置

### ThemeStore
主題儲存管理器，負責主題的儲存和載入

### ThemeManagerPage
主題管理頁面，提供主題選擇和預覽介面

### ThemeFunctions
主題相關的工具函式

## 功能
- 預設主題 (Default Theme)
- 粉紅主題 (Pink Theme)
- 電子紙主題 (E-Ink Theme: 白底黑字、黑白對調深色版)
- 系統深色模式跟隨 (Follow System Dark Mode)
- 主題切換與預覽

## 主題類型
- 預設外觀 (Default / Dark)
- 粉紅外觀 (Pink / Pink Dark)
- 電子紙外觀 (E-Ink / E-Ink Dark)
